## 快速开始

### 方式一：使用 EXE（最简单）

1. 双击 `CyberMiao.exe`
2. 首次运行看到欢迎界面
3. 点击"配置"标签页
4. 填写 DashScope API Key（[获取地址](https://dashscope.console.aliyun.com/)）
5. 点击"保存配置"
6. 返回"主控制台"标签页
7. 点击"🚀 启动服务器"
8. 浏览器自动打开，开始使用！

### 方式二：从源码运行

```powershell
# 1. 安装依赖
python setup.py

# 2. 启动程序
python src/launcher.py
```

## 功能介绍

### 🎤 语音对话

- **实时语音输入输出**：端到端语音对话，无需文字转换
- **支持中英文**：自动识别语言
- **自然对话**：基于 Qwen 3.5 Omni 大模型
- **低延迟**：流式处理，响应迅速

**使用方法**：
1. 在网页界面中点击麦克风图标
2. 对着麦克风说话
3. AI 实时语音回复

### 👁️ 视觉问答

- **摄像头画面理解**：对话时自动抓取摄像头画面
- **实时画面查看**：网页 viewer 显示实时画面
- **多模态对话**：结合语音和视觉理解

**使用方法**：
1. 确保摄像头已连接
2. 在对话中提问关于画面的问题
3. 例如："你看到了什么？"

### 🌐 同声传译

- **中英互译**：实时双向翻译
- **语音输出**：翻译结果以语音形式输出
- **独立会话**：进入翻译模式会重建会话

**使用方法**：
1. 在网页界面中切换到"翻译模式"
2. 说中文，AI 用英文回复
3. 说英文，AI 用中文回复

### 🎭 表情动作

- **15 个预设动作**：高兴、生气、思考等
- **待机随机动作**：自动执行随机动作保持活跃
- **TFT 屏幕显示**：本地表情动画，节省带宽

**动作列表**：
1. 点头 - 表示同意
2. 摇头 - 表示否定
3. 高兴 - 开心表情
4. 生气 - 愤怒表情

## 详细配置

### API Key 配置

**获取 DashScope API Key**：
1. 访问 [DashScope 控制台](https://dashscope.console.aliyun.com/)
2. 注册/登录阿里云账号
3. 创建 API Key
4. 复制 Key（格式：sk-xxxxxxxxxx）

**填写到程序**：
1. 打开"配置"标签页
2. 粘贴到"DashScope API Key"输入框
3. 点击"💾 保存配置"

### 服务器配置

**端口设置**：
- 默认端口：8081
- 如果被占用，可以修改为其他端口（例如：8082）
- 修改后需要重启服务器

**自动打开浏览器**：
- 勾选后，启动服务器时自动打开浏览器
- 取消勾选则需要手动访问

**配置文件位置**：
- 开发模式：`CyberMiao_App/config/settings.ini`
- EXE 模式：`config/settings.ini`（与 EXE 同目录）

## ESP32 硬件配置

### 硬件准备

**所需硬件**：
- ESP32 开发板
- 舵机 x N（根据设计）
- TFT 屏幕
- 摄像头模块
- 电源适配器

### 固件烧录

1. **打开 Arduino IDE**
2. **加载固件**：`esp32_servo_control/esp32_servo_control/esp32_servo_control.ino`
3. **选择开发板**：ESP32 Dev Module
4. **配置分区表**：选择自定义分区表 `esp32_servo_control/partitions.csv`
5. **编译并烧录**

### WiFi 配网

**首次配网**：
1. ESP32 开机后自动进入配网模式
2. LED 指示灯闪烁
3. 手机搜索 WiFi 热点：`CyberMiao-Setup`
4. 连接热点（无密码）
5. 浏览器自动打开配网页面（或手动访问 `192.168.4.1`）

**填写配置**：
1. **WiFi 名称**：你的家庭 WiFi 名称
2. **WiFi 密码**：你的家庭 WiFi 密码
3. **服务器 IP**：电脑的局域网 IP（在程序"主控制台"中查看）
4. 点击"保存"

**配网成功**：
- ESP32 自动重启
- 连接到家庭 WiFi
- 连接到服务器
- 屏幕显示正常表情

### 查看本机 IP

在程序的"主控制台"标签页中，会显示：
```
🌐 本机 IP: 192.168.1.100
🔌 服务端口: 8081
📱 ESP32 配置 IP: 192.168.1.100
```

将显示的 IP 地址填写到 ESP32 配网页面的"服务器 IP"中。

**注意事项**：
- ⚠️ IP 地址可能会变化（DHCP 动态分配）
- ⚠️ 如果 IP 变化，需要重新配网
- ⚠️ 建议在路由器中为电脑设置固定 IP

## 常见问题

### Q1: 启动后报错"未配置 API Key"？

**A**: 
1. 进入"配置"标签页
2. 确保填写了正确的 DashScope API Key
3. 点击"保存配置"
4. 重新启动服务器

### Q2: 端口被占用怎么办？

**A**:
1. 关闭其他占用 8081 端口的程序
2. 或在"配置"中修改为其他端口（如 8082）
3. 保存配置后重启

### Q3: ESP32 连接不上服务器？

**A**:
1. **检查 IP 地址**：确认填写的是最新的电脑 IP
2. **检查网络**：确保电脑和 ESP32 在同一局域网
3. **检查防火墙**：
   - 打开"Windows 防火墙"
   - 允许 Python 或 CyberMiao.exe 通过防火墙
   - 允许 8081 端口入站
4. **查看日志**：ESP32 串口监视器查看连接错误信息

### Q4: 摄像头无法使用？

**A**:
1. 检查摄像头是否连接
2. 检查是否被其他程序占用
3. 在 Windows "相机"应用中测试摄像头
4. 查看程序日志中的错误信息

### Q5: 语音无法输入/输出？

**A**:
1. 检查麦克风权限
2. 检查扬声器/耳机连接
3. 在浏览器中允许麦克风权限
4. 查看网页控制台的错误信息

### Q6: 打包的 EXE 太大？

**A**: 
这是正常的（约 200-400 MB），因为包含：
- OpenCV（图像处理）
- MediaPipe（手势识别）
- NumPy（数值计算）
- AI SDK（DashScope）

**优化建议**：
1. 如果不需要手势识别，可以移除 MediaPipe
2. 编辑 `build_config.py` 的 `excludes` 列表
3. 重新打包

### Q7: 启动很慢？

**A**:
- 首次启动需要解压临时文件（5-10 秒）
- 后续启动约 2-3 秒
- AI 模型加载需要时间
- 这是正常现象

### Q8: 配网时无法访问 192.168.4.1？

**A**:
1. 确认手机已连接到 `CyberMiao-Setup` 热点
2. 手动在浏览器中输入 `http://192.168.4.1`
3. 关闭手机的移动数据（避免自动切换网络）
4. 尝试使用其他浏览器

## 高级功能

### 命令行参数

开发模式可以使用命令行参数：

```powershell
# 指定端口
python src/launcher.py --port 8082

# 指定配置文件
python src/launcher.py --config custom_config.ini

# 启用调试模式
python src/launcher.py --debug
```

### 配置文件结构

`config/settings.ini` 文件格式：

```ini
[Server]
host = 0.0.0.0
port = 8081
auto_open_browser = true

[API]
dashscope_api_key = sk-xxxxxxxxxxxxxx

[UI]
theme = light
language = zh_CN
```

### 日志文件

- **位置**：程序运行目录
- **文件名**：`cyberMiao.log`
- **包含内容**：启动日志、错误信息、调试信息

### 防火墙规则

**Windows 防火墙添加规则**：

```powershell
# 允许 Python
netsh advfirewall firewall add rule name="CyberMiao Python" dir=in action=allow program="C:\Python\python.exe" enable=yes

# 允许 8081 端口
netsh advfirewall firewall add rule name="CyberMiao Port 8081" dir=in action=allow protocol=TCP localport=8081
```

### 性能优化

**减少内存占用**：
1. 关闭不需要的功能（如视觉问答）
2. 降低摄像头帧率
3. 减少动作库数量

**提高响应速度**：
1. 使用更快的 AI 模型
2. 优化网络连接
3. 使用固定 IP 减少 DNS 查询

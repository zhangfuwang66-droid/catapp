## 🔨 打包步骤

### 步骤 1: 清理旧构建

```powershell
# 删除旧的构建文件
Remove-Item -Recurse -Force build, dist, __pycache__ -ErrorAction SilentlyContinue
```

### 步骤 2: 生成配置

```powershell
# 生成 .spec 文件
python build_config.py
```

检查：
- [ ] `CyberMiao.spec` 文件已生成
- [ ] 文件路径正确
- [ ] 图标路径正确

### 步骤 3: 执行打包

```powershell
# 方式 1: 使用自动化脚本（推荐）
python build.py

# 方式 2: 手动打包
python -m PyInstaller CyberMiao.spec --clean --noconfirm
```

## ⚠️ 常见打包问题

### 问题 1: ModuleNotFoundError

**症状**: 打包的 EXE 启动报错找不到模块

**解决**:
1. 检查 `build_config.py` 的 `hiddenimports`
2. 添加缺失的模块名
3. 重新生成 .spec 文件
4. 重新打包

### 问题 2: 文件体积过大

**症状**: EXE 文件超过 500 MB

**解决**:
1. 检查 `excludes` 列表
2. 添加不需要的大型库（如 matplotlib, pandas）
3. 启用 UPX 压缩
4. 移除不需要的数据文件

### 问题 3: 图标不显示

**症状**: EXE 没有自定义图标

**解决**:
1. 确认 `assets/icon.ico` 存在
2. 运行 `python create_icon.py` 生成图标
3. 重新生成 .spec 文件
4. 重新打包

### 问题 4: UPX 压缩失败

**症状**: 打包时 UPX 压缩报错

**解决**:
1. 下载 UPX: https://upx.github.io/
2. 将 upx.exe 放到 PATH
3. 或在 .spec 中设置 `upx=False`

### 问题 5: 启动黑屏或无响应

**症状**: EXE 启动后无界面或卡住

**解决**:
1. 检查是否设置了 `console=False`
2. 临时改为 `console=True` 查看错误
3. 检查 tkinter 是否正确打包
4. 检查所有依赖是否完整

# 赛博小喵使用说明

## 下载与启动

GitHub Releases 提供两个 Windows x64 版本：

- `CyberMiao-Setup-x64.exe`：安装到当前 Windows 用户目录，提供开始菜单入口、可选桌面快捷方式和卸载程序。
- `CyberMiao-Portable-x64.exe`：免安装，下载后直接运行。

两个版本共用 `%LOCALAPPDATA%\CyberMiao` 中的配置和数据。卸载安装版不会删除该目录。GitHub 页面还会自动提供源码 ZIP 和 tar.gz。

1. 启动安装版或便携版。发行包已包含 Python 和程序运行库。
2. 在“连接设置”页填入自己的 DashScope API Key。可从[阿里云百炼控制台](https://bailian.console.aliyun.com/)获取。
3. 默认端口是 `8081`。点击“保存配置”，确认页面显示已保存。
4. 切换到“工作台”，点击“启动服务”。状态变成“运行中”后才表示已完成端口监听。
5. 点击“打开网页”，或访问 `http://127.0.0.1:8081`。勾选自动打开时，程序会在服务就绪后打开浏览器。

API Key 填入和本地健康检查不代表云端鉴权成功。实际语音和视觉对话需要有效 Key、对应模型权限和网络。

## 新版界面

- 左侧切换“工作台”“连接设置”和“关于”，常用操作固定在右上角。
- 工作台的“服务概览”展示服务状态和连接入口；“运行日志”支持自动滚动、异常着色和清空视图。
- “清空视图”只清除界面文字，不删除磁盘日志。“复制”按钮复制对应的本机网址或设备地址。
- `Ctrl+1` 打开工作台，`Ctrl+2` 打开设置，`Ctrl+L` 查看日志；在设置页按 `Ctrl+S` 保存。
- 缩小窗口后可用滚轮查看完整内容。未配置 Key 时，首次启动直接显示连接设置。

## 连接 ESP32

让电脑和 ESP32 连接同一局域网。将主控制台显示的 IP 和端口填写到 ESP32 的服务器配置中。

IP 根据系统到外网的默认路由推导。使用 VPN 或多网卡时，请核对它是否与 ESP32 所在网段一致。IP 显示 `127.0.0.1` 时，只能本机访问，需要先检查网络。Windows 防火墙是否允许局域网连接需由用户根据自己的网络环境设置。

## 停止、重启和托盘

- 服务卡片中的“停止”会关闭网络连接并回收服务进程；完成后状态显示“已停止”。
- 修改 Key 或端口后先保存，再点服务卡片的“重启”应用配置。
- “收起到托盘”隐藏窗口并保持服务运行。双击托盘图标或右键选“显示主窗口”恢复。
- 托盘菜单也可以启动、停止服务或退出。
- 点击窗口右上角关闭按钮或托盘“退出”，程序会先停止服务再退出。普通最小化保留在任务栏。

停止通常会等待连接正常关闭；超过等待时间后，程序会结束自己创建的服务进程，并在日志中注明。

## 配置和数据

默认用户数据目录为 `%LOCALAPPDATA%\CyberMiao`。开发模式和 exe 使用同一默认目录。

- `settings.ini`：API Key、端口和自动打开网页选项。Key 以普通文本保存，请勿分享该文件。
- `logs/CyberMiao.log`：运行日志，达到 2 MiB 后轮转，最多保留 3 份备份。已知 Key 会在写入日志前隐藏。
- `records/`：服务器生成的录制分析图片等数据。
- `models/`：用户缓存模型；发行包自带手部识别模型时优先使用缓存，其次使用内置模型。

通过侧栏的“日志文件夹”或“关于 → 打开用户数据目录”可找到这些文件。升级时安装新版或替换便携版即可，配置和录制数据保存在用户目录。源码中的 `desktop/assets/icon.ico` 已嵌入 exe，资源管理器可以直接显示应用图标。

如果用户目录尚无配置，程序会迁移旧版 exe 旁 `config/settings.ini`；开发模式会读取旧的 `desktop/config/settings.ini` 并迁移一次。示例配置 `settings.example.ini` 不包含真实 Key。

开发和隔离测试可通过环境变量 `CYBERMIAO_DATA_DIR` 指定独立数据目录。

## 排查问题

- 无法启动：先看运行日志。Key 未保存、端口被占用会给出提示；可更换端口或关闭占用端口的程序后重试。
- 本机健康检查：访问 `http://127.0.0.1:8081/api/health`，正常返回 `OK`。如果修改过端口，请替换地址中的端口。
- 网页正常、对话报错：检查 DashScope Key、模型权限和网络；健康检查不会向云端发送请求。
- ESP32 无法连接：核对局域网 IP、端口和设备网络；本机健康检查不验证设备连接。
- 日志显示 MediaPipe/OpenCV 加载失败：请使用重新构建并通过运行检查的完整发行版。

本机自动检查不包含真实 API 调用、ESP32 舵机/音频/摄像头联调，也不代表其他 Windows 机器已验证。下载版本的功能与验证范围请查看对应 Release 的中文公告；源码接入说明见[服务器文档](../server/README.md)。

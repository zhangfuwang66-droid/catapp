# Windows 版本发布

发布公告统一使用中文，按实际改动与验证结果编写。

1. 更新 `desktop/VERSION`，例如 `0.2.0`。界面显示、安装器版本和发布标签以此为准。
2. 新建 `docs/releases/v<版本号>.md`，写清更新内容、下载选择、升级方式和未验证范围。
3. 更新界面截图和使用说明；截图使用隔离配置与测试 Key。
4. 运行 `python -m unittest discover -s desktop/tests -v`，必要时在本机执行调试构建。
5. 检查变更并提交，推送 `main`，再创建并推送同版本标签，例如 `v0.2.0`。
6. 等待 GitHub Actions 的“构建并发布 Windows x64 版本”完成，核对公告、版本和两个 exe 附件。

工作流会先校验标签与 `desktop/VERSION` 一致且对应中文公告存在，再安装依赖、运行测试、打包并检查生成的 exe；随后在独立目录安装，核对文件内容和主程序哈希，检查安装后运行及卸载。全部成功后才创建 Release。公告直接读取仓库文件，不再自动附加英文提交摘要。

正式软件包只提供 Windows x64 安装版和便携版，源码 ZIP / tar.gz 由 GitHub 自动生成。本机构建方法与产物路径见 [桌面端说明](../desktop/README.md)。

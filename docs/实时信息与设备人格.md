# 实时信息与设备人格

以下为开发分支源码能力，需将对应版本部署到后端；旧版 exe 不会自动获得更新。模型回答和实物效果仍需在目标服务验收。

## 时间与天气

可以问「现在北京时间几点」「今天几号、星期几」。后端在每轮普通对话中提供服务器当前的北京时间，时区为 `Asia/Shanghai`；准确度依赖服务器时钟。普通闲聊不会为此调用外网或额外模型。

天气查询需要明确受支持城市，例如「北京现在的天气怎么样」「上海明天会下雨吗」。后端使用 Open-Meteo，支持今天的当前观测，以及明天、后天的预报。今天的观测不能据此保证整天或夜间不会下雨；指定其它日期时提示当前能力限制。

地点只从源码维护的常见城市目录匹配，不接受任意聊天片段作为地名。目录覆盖国内常见城市及少量海外城市，未覆盖城市或地点有歧义时会询问，不根据 IP、记忆或资料猜位置。地理编码结果还须匹配可信国家和行政范围，不能随意选择同名村落。

城市坐标缓存 24 小时，天气缓存 5 分钟；单次查询最多等待约 3 秒，失败时明确说明暂时查不到。只向天气来源发送城市名或坐标与日期参数，不发送整段语音、聊天、Key 或个人资料。闲聊、翻译模式和文档问答不应触发天气查询；不会额外调用付费模型来搜索天气。

## 保留每台原有性格

已知猫、鹿分别使用自己的完整原始人格模板。首次运行按稳定设备编号在数据目录的 `personas/` 建立档案，包含版本和提示词摘要；设备改名、换主人或升级代码均不覆盖已有档案。退出翻译或视觉模式后仍回到这台设备的人格。未知类型或损坏档案暂停模型对话，等待管理员核对。

猫和鹿的已知模板不能代表任意新设备的原性格。其它设备应先从可信源码或配置保存原档案，不能仅凭同款硬件或一份二进制备份推断。固件升级只写主程序，表情和配网音等资源保留在原文件系统；云端人格与 Flash 资源分别核验。

完整人格档案属于运行数据，已加入 Git 忽略。升级工具可使用后端导出的私密档案校验编号与摘要；离线摘要匹配不能代替目标云端实际加载及实物验收。参见[同款设备升级与功能清单](同款设备升级与功能清单.md)。

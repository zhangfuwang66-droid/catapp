# 数据库完善记录

## 2026-11-05：运行日志与录制空间管理

- 聊天输入、回复、ASR 事件及图片描述不再写入普通运行日志，只保留事件和长度；上游错误仅记录受限的类型和代码，避免请求正文被回显。API Key、Bearer 和常见凭证字段过滤后才进入日志。
- 直接运行后端时写入轮转日志，单文件约 2 MiB、历史 5 份。Linux 下首次创建及轮转后的文件均为属主读写；桌面入口保持原有日志通道。
- 新增受管理录制图片的后台巡检，默认 7 天、总量 1 GiB、预留磁盘 512 MiB。当前列表与正在写入/描述的图片受保护；仅处理应用约定路径，不删除数据库、备份或手工文件。
- 配额或磁盘空间不足时，暂停受影响设备的录制并向网页报告状态；不调用图片描述模型，也不停止其他设备。

服务器回归共 115 项，114 项通过，1 项因 Windows 用户无符号链接权限而跳过；桌面 7 项通过。覆盖日志轮转脱敏、图片过期/容量/低磁盘、路径越界和覆盖保护、使用中图片保护、巡检退出，以及设备录制暂停的通知与隔离。Linux 符号链接边界仍需在云端补测。全部自动化测试使用临时数据库及模拟内容，不代表云端已部署或实物已验收。

## 2026-11-05：版本保护与数据关联检查

此轮为第二阶段之后的本机开发，不依赖 USB，不改云服务器配置。云端现有数据库仍是第 0 步初始化的空库，服务尚未上线。

- 给记忆表增加独立版本 `memory=1`，复用已有的组件版本表。无版本完整旧库在事务内登记，原消息不重建、不删除；结构不完整或任一已知组件版本高于程序时拒绝写入。身份组件仍为第二版。
- 新创建的记忆数据库以仅属主读写权限创建（Windows 的实际访问权限依赖文件夹 ACL）。
- 总结结果必须引用本会话的精确消息编号。取得写锁后检查已总结进度，两个实例同时写同批或迟到重试只保留一次；重复结果不更新事实。读取上下文的三类数据使用一个快照。
- 只读 `inspect` 增加组件版本、身份表数量、外键、事实和会话归属、总结边界、账号设备归属，以及待总结会话和空间统计。不输出任何聊天、账号、凭证或哈希正文。

新增九项临时数据库测试通过：无版本旧库保留数据、未来版本双向拒绝、建表失败完整回滚、残缺旧库拒绝、两个实例并发提交去重、跨会话边界拒绝、身份/空间统计无私密内容、孤儿与跨归属记录、异常总结进度。服务器整体回归 76 项通过；测试使用模拟内容，没有访问真实云端或串口。

## 2026-11-05：独立备份与可审阅恢复

- 新增 `restore` 子命令，默认只读预览，实际执行要求停止服务确认、独立备份和另行保存的 SHA-256。只生成新文件，不覆盖数据库或遗留旁文件，不自动改后端配置。
- 在同盘私密临时目录完成恢复、检查与会话撤销，再以硬链接无覆盖发布；失败不留下半成品。原数据库、源备份不修改。
- 恢复后撤销全部备份内网页登录会话、作废未领取配对码，保留记忆和设备绑定。长期设备凭证及密码回到备份时的状态，旧备份之后的变更需要管理员核对，不能把恢复当作撤销记录的合并。
- 备份工具拒绝目标同名的 WAL/SHM/journal，超时后清理本次创建的半成品。SHA-256 计算兼容云端 Python 3.10。

八项恢复测试通过：只读预览、校验/停服/覆盖保护、真实身份模拟数据的恢复与会话作废、旁文件保护、运行中 WAL 拒绝、不兼容或损坏源拒绝、发布失败清理、备份超时清理。所有数据库均在临时目录，未恢复真实聊天或修改云端文件。

## 2026-11-05：长连接退出清理

完整回归发现退出 WebSocket 的偶发取消错误，复现测试 25 次出现 6 次错误。原因是 ASGI 重复取消打断巡检任务的清理，`asyncio.gather` 可能把取消来源替换为子任务的无来源取消异常。清理阶段增加 AnyIO 屏蔽域，等待巡检完成；外部真正取消仍向上传播，不隐藏业务异常。

修复后同场景重复 25 次通过，另有两项针对性测试通过：ASGI 取消期间等待清理完成，以及外部任务取消保留原始原因。第一项测试已验证能识别旧实现的问题。

## 2026-11-05：可选自动备份与就绪探针

- 设置 `CYBERMIAO_BACKUP_DIR` 才启用定时任务。默认每 6 小时一次，保留最新 28 份有效快照；重启识别近期快照，避免重复生成。
- 快照和校验清单均私密创建。复制使用 SQLite 一致性备份接口，不直接复制运行中的主文件；低磁盘、复制超时和清单发布失败均有保护。停止服务时等待已开始的备份线程完成。
- 按严格命名、源库路径标识、大小和 SHA-256 再次校验后轮换。手工、其他源和损坏记录保留；降低保留数量后无需等待新快照即可轮换。自动生成的 SQLite 文件、旁文件和清单加入 Git 忽略规则。
- 新增只读 `backup-status`，源库丢失仍可查看同源备份；只输出备份元数据。新增 `/api/ready`，数据库不可读或必需结构异常返回 503，响应不暴露路径和 SQL。原 `/api/health` 行为保留。
- 本轮默认配置未启用自动备份，没有写入真实聊天库、修改云端、烧录或打包。云端尚需上传新版后端、配置服务和备份目录；异机备份及云端恢复演练待部署时完成。清除当前记忆不会同时清除历史备份。

17 项自动备份与就绪检查测试通过，包含低磁盘、同名保护、损坏清单、失败重试、源库丢失后列备份、重启轮换、服务关闭和就绪响应脱敏。服务器完整回归 103 项通过，桌面相关 5 项通过。测试只使用临时数据库、模拟模型和模拟设备，不表示云端、真实模型或实物已验收。

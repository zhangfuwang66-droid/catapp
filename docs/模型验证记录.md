# 真实模型验证记录

## 2026-11-05

使用百炼中国站接口及用户本机保存的 API Key。只发送固定测试文本、Windows 本地合成语音与纯色 JPEG，不采集麦克风、摄像头或真实聊天。报告不包含 Key 或对话正文，详细产物保存在 Git 忽略的 `artifacts/model-probes/`。

### 已通过

- `qwen3.8-omni-flash-realtime` 配合 `Tina`：鉴权、会话建立、固定文本输入、文本及 PCM 语音输出。
- 使用项目实时客户端，输入 16 kHz 单声道 PCM 和合成蓝色图片：取得输入转写，正确回答图片主色，返回文本及 53,760 字节语音，响应状态为 `completed`。
- 长回复产生音频后发送 `response.cancel`：服务端确认 `cancelled`。此项验证取消接口，不等同于实体小猫麦克风打断及扬声器停播验收。
- 关闭客户端会话后重新建立连接：再次取得文本及语音，响应状态为 `completed`。未模拟公网长时间掉线、进程崩溃或设备断电。
- `qwen-plus` 文本摘要：固定合成对话返回包含 `summary`、`memories`、`open_topics` 的 JSON。

### 尚未通过或尚未验证

- 同一个实时模型使用当前默认音色 `Sunnybobi`：会话建立后返回 `COMMON_ERROR`，本轮未取得音频。换用 `Tina` 后成功；尚无证据判断所有音色及语言组合的支持范围。
- 普通 `qwen3.8-omni-flash` 使用项目现有 `text/audio` 参数：HTTP 400，`invalid_parameter_error`。需要独立适配，不能用实时链路成功替代普通聊天接口验收。
- 旧独立视觉模型 `qwen-vl-plus`：HTTP 404，`model_not_found`。实时会话图片理解成功，不代表活动记录描述接口已修复。
- 情绪解析、多设备真实并发、实体固件 TLS/音频/画面尚未完成本轮真实验收。

### 复现基础探测

从仓库根目录运行，按需选择检查项，避免无关的模型请求：

```powershell
& 'D:\Python313\python.exe' server/tools/probe_models.py --checks realtime summary --realtime-model qwen3.8-omni-flash-realtime --realtime-voice Tina --output artifacts/model-probes/check.json
```

Key 优先读取进程环境，其次 `server/.env`，最后桌面程序用户数据目录中的 `settings.ini`。不要在命令参数或 Git 文件中填写 Key。该工具会发起真实调用并产生供应商计费；默认检查全部四个接口，返回失败退出码表示至少一个所选检查未通过。

模型和音色参数仅作用于测试进程，不修改项目默认配置。此次没有合并原作者功能分支、烧录固件或重新打包 exe。下一步云端测试可在独立环境中使用已验证组合；正式修改软件默认值需按用户后续要求另行提交。

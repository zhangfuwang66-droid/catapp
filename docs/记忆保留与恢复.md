# 记忆保留与恢复

在「查看记忆 → 记忆保留方式」选择用途：

- **长期使用**：默认保留聊天、摘要和重要事实，不按闲置时间清除。
- **临时体验**：连续闲置三十天，且消息全部总结后，后台按小时巡检并压缩可节省空间的聊天原文。临时借用的新使用记录默认采用此方式。

两种方式都不会自动永久删除记忆。归档保留摘要、重要事实和消息编号，之后继续聊天仍可使用摘要；原文以 gzip 压缩块保存在同一数据库，可点击「恢复压缩的原文」恢复。未总结的消息不压缩，小片段压缩反而增大时保留原文。

修改保留方式或恢复原文后，会重新计算闲置宽限期。新聊天会更新活跃时间。设备归还或解绑不改变历史记忆的账号归属，其他使用者不能查看或恢复你的原文。

数据库备份包含压缩块。检查和恢复会校验内容摘要、消息编号和归属；校验失败时整批回滚。正常清除个人设备记忆会同时删除对应归档；已有备份仍按备份策略留存。

压缩让数据库页可复用，不保证 SQLite 文件立刻变小，也不会自动运行需要独占锁的 VACUUM。图片、音频、资料原文和备份使用各自的空间管理规则，不包含在聊天原文压缩中。

本次未启用一个月后永久删除账号或整库的任务。如需自动永久删除，应另行确定原文、摘要、重要事实和备份各自的期限。

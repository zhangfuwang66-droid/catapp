# 设备转交与借用

联网配置和账号归属分别管理：无网时先配网；联网但未绑定时，在小喵屏幕查看配对码；绑定后使用当前账号的模型设置、资料和记忆。换主人无需重新填写同一个 Wi-Fi。

## 永久转交

在「我的小喵 → 转交与借用」选择永久解绑，输入设备编号确认。服务器终止旧账号的控制、音频和画面连接，保留硬件凭证与网络。小猫重新确认未绑定状态后获取配对码，新主人登录自己的账号并添加设备。

原主人的 Key、资料与聊天不会转给新主人。原主人可在「我的历史记忆」查看或清除属于自己的记录。停用设备仍是单独的管理操作，会撤销硬件凭证，不能代替普通解绑。

## 临时借用

长期主人选择 1 小时、4 小时、1 天或 7 天，生成五分钟有效的一次性借用码。对方登录独立账号，在添加小喵时选择「临时借用」接收。接收前主人仍可使用；接收后只有借用者可以控制、查看实时画面和对话。

借用者使用自己的 Key、资料和聊天记忆，主人不能读取其私聊。主人和借用者都可提前结束；到期自动归还。双方的历史记忆分别保留。暂未提供公开自助注册，独立账号由管理员创建。

语音暂停设置按账号和设备保存，模型重连或服务重启不会主动恢复已暂停的语音。恢复数据库备份会结束借用、撤销网页会话和未领配对码；上线前需核对恢复后的硬件凭证。

屏幕状态和及时复查绑定需要本次固件更新。源码和模拟测试不代替实际联网解绑、接收和到期归还的硬件验收；烧录前另行说明并确认。

# 设备转交与借用

联网配置和账号归属分别管理：无网时先配网；联网但未绑定时，在小喵屏幕查看配对码；绑定后使用当前账号的模型设置、资料和记忆。换主人无需重新填写同一个 Wi-Fi。

## 永久转交

在设备卡片点击「解绑 / 转交」，输入设备编号确认。服务器终止旧账号的控制、音频和画面连接，保留硬件凭证与 Wi-Fi。设备重新确认未绑定状态后获取配对码，新主人登录自己的账号并添加设备。新绑定默认暂停语音，在控制台确认自己的模型 Key 后再主动开启。

原主人的 Key、资料与聊天不会转给新主人。原主人可在「我的历史记忆」查看或清除属于自己的记录。停用设备仍是单独的管理操作，会撤销硬件凭证，不能代替普通解绑。

## 凭证撤销与 USB 恢复

设备卡片的「安全操作 → 撤销凭证（遗失设备）」用于遗失或凭证泄露。撤销后屏幕不会自动显示配对码；重新配 Wi-Fi 或重启设备都不能恢复旧凭证。

管理员在设备详情选择「恢复设备（USB）」并确认编号。已撤销但仍有旧主人时，恢复会结束旧绑定和借用，历史记忆留在原账号；正常使用中的已绑定设备必须先解绑。新凭证只显示一次，下载为 `.secret.json` 文件后，通过 USB 配发：

```powershell
python firmware/tools/provision_device.py --port COM3 provision --credential-file '设备凭证.secret.json'
```

端口以实际识别结果为准。配发工具会核对设备编号，保留网络与服务器地址，设备随后重启。联网后在屏幕查看配对码，再用自己的账号绑定。后台签发成功仅表示生成了新凭证，不表示它已经写入实体。凭证不可发到聊天或 Git。

只有已撤销且无绑定、记忆或历史关联的误登记空设备才允许永久删除。有历史的设备保留记录；空记录删除后重新使用仍需重新登记、签发并通过 USB 配发新凭证。

## 临时借用

长期主人点击「临时借用」，选择 1 小时、4 小时、1 天或 7 天，生成五分钟有效的一次性借用码。对方登录独立账号，在添加小喵时选择「临时借用」接收。接收前主人仍可使用；接收后只有借用者可以控制、查看实时画面和对话。

借用者使用自己的 Key、资料和聊天记忆，主人不能读取其私聊。主人和借用者都可提前结束；到期自动归还。双方的历史记忆分别保留。暂未提供公开自助注册，独立账号由管理员创建。

语音暂停设置按账号和设备保存，模型重连或服务重启不会主动恢复已暂停的语音。恢复数据库备份会结束借用、撤销网页会话和未领配对码；上线前需核对恢复后的硬件凭证。

屏幕状态和及时复查绑定需要本次固件更新。源码和模拟测试不代替实际联网解绑、接收和到期归还的硬件验收；烧录前另行说明并确认。

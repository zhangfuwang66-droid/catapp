# 更懂口语的语音识别

在控制台打开「语音识别设置」，按账号选择方式。默认仍是快速模式，没有额外识别请求，也没有人为等待几百毫秒的步骤。

- **快速**：使用实时模型最终识别文本，再应用你明确填写的词语替换，例如「欧诶 → OA」。替换只匹配原词，不模糊猜测，不链式替换。
- **精准**：用本轮 16 kHz 单声道音频再调用一次 Qwen-ASR，带上个人热词和当前账号的资料话题。最多额外等待约三秒，增加识别模型用量；失败、超时或音频不完整时回到原识别。

精准模式在内存中最多暂存二十五秒音频，连接关闭时清空，不额外写录音文件。更长或缺少开头的语句可能跳过二次识别。主要语言可选中文、粤语、英语或自动；混合语言建议自动。同声传译保留原流程，不走二次识别。

网页会显示正在核对、最终校正或回退状态。校正在动作匹配、资料检索和聊天记忆写入之前完成。两次识别出现数字或日期冲突时，小喵先询问确认，本轮不检索、不执行动作，不把候选存入长期记忆。

这能改善部分专有名词和口语识别，不保证所有方言、背景噪声或人名都识别正确。精准模式是可选项，不能据此承诺响应比快速模式更快。错误词可在个人词表中明确修正，重要信息仍需核对。

## 接口与配置

按[百炼 Qwen-ASR 文档](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)使用音频输入和上下文词表。没有向现有实时协议添加未经核实的热词或纠错参数。

- `QWEN_ASR_MODEL`：默认 `qwen3-asr-flash`，用于二次识别。
- `DASHSCOPE_ASR_COMPAT_BASE`：可选；默认与其他百炼兼容接口相同。需匹配账号 Key 的地域和该模型可用接口。
- 保留现有实时对话模型、音色和 VAD 配置。

本次自动测试使用模拟模型，验证了音频边界、Key 和词表隔离、回退、取消与记忆保护。精准模式仍需在部署后用真实 Key 和实体设备验收准确率、延迟和地域兼容性。

# 账号模型设置

账号模式中，登录并绑定小猫后，在控制台顶部打开「模型设置」，保存自己的百炼 API Key，再点击「测试连接」。测试会调用一次短文本并建立实时语音连接，产生少量模型用量；不代表摄像头、硬件播放或所有模型权限均已验收。

- Key 属于账号，同一账号的设备使用相同配置。聊天、视觉、情绪、记忆总结和资料向量索引均按账号取 Key。
- 没有配置时仍可登录、绑定、管理资料和查看已有记忆。AI 对话不可用；资料可降为本地关键词索引，不使用服务器共用 Key。
- 更新或移除 Key 会断开该账号现有模型连接，其他账号不受影响。小猫联网后会重新连接；资料和记忆保留。
- 网页不回传完整 Key，不把 Key 写入硬件。本地桌面兼容模式仍使用原来的环境变量配置。

## 管理员备份要求

数据库的 `account_provider_keys` 表仅存 AES-GCM 密文。主密钥默认位于数据库旁的 `provider.key`，也可通过 `CYBERMIAO_SECRET_KEY_FILE` 指定独立文件。主密钥不得提交 Git，应限制为服务账号读取。

备份和恢复必须同时保管数据库与对应主密钥，建议分开存放。只有数据库备份无法解密 Key；主密钥遗失或不匹配时系统拒绝读取，不会静默重新生成密钥覆盖已有密文。首次保存账号 Key 时才创建主密钥。

升级前应停止写入并制作可验证备份。新数据库组件版本会阻止旧程序降级写入；回退代码时应恢复升级前数据库快照，不能只切回旧代码。此文件描述源码能力，云端上线和真实用户 Key 验收需另行执行。

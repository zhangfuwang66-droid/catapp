# 个人资料库

适用于 `main` 分支源码，尚未打包进 `v0.2.0`。需要升级运行中的后端；只更新网页或下载旧版 exe 不会获得这项功能。资料库保存在服务器，不要求修改小猫固件或重新烧录。

## 上传和提问

1. 打开运行中的服务网页，登录自己的账号，从“我的资料库”进入。也可直接访问同一地址下的 `/knowledge`。
2. 选择或拖放文件，等待处理完成。“可检索”表示已有向量索引，“关键词可用”表示可以按关键词查找，暂时没有可用的向量索引。
3. 在“试着查一查”输入文档中的问题，核对命中的文件和片段。
4. 回到小喵控制台，用文字或麦克风提出相关问题。服务会先检索当前账号的资料，再交给模型回答；控制台显示参考文件名与片段序号。实时语音沿用设备当前的对话方式。

例如上传一份产品手册后，可以问“这份产品手册里的配网步骤是什么？”。相关资料不足时，请补充文件或把问题说得更具体。引用文件不等于答案必然正确，关键内容应核对原文。

## 文件和容量

支持带文字的 PDF、DOCX、TXT、Markdown、CSV、JSON 和 HTML。暂不支持扫描件 OCR、旧版 DOC、表格 XLSX、图片识别或网页链接导入。HTML 只提取文字，不执行脚本、不抓取链接；DOCX 不执行宏。

默认限制如下，容量单位为 MiB（1 MiB = 1024 × 1024 字节）：

- 单文件最多 20 MiB，PDF 最多 100 页，提取正文最多 20 万字符。
- 每账号最多 40 个文件、100 MiB 原文件、3000 个文字片段。
- 服务全局最多 1 GiB 原文件、30000 个文字片段；还需为数据库索引、日志与备份预留空间。
- 磁盘可用空间不足 512 MiB 时拒绝新上传。

同账号上传相同内容会复用已有文件，不重复占名额。文档依次处理，较大文件需要等待。解析失败时原文件仍保留，可下载、删除或重建；加密 PDF、空白扫描件和超过限制的文件需要先处理后再上传。

向量接口失败时会降为关键词检索，原文件不会因此丢弃。恢复 API 额度或网络后，可点“重建索引”。异常重启后，未完成任务会重新排队。

## 账号、数据和删除

同账号绑定的小喵共享资料库，不同账号的文档与检索结果分别管理。聊天记忆仍按账号和设备保存。本地兼容模式没有个人登录隔离，访问该服务的人使用同一个默认资料库；需要多人独立使用时采用账号模式。

原文件、提取片段和向量保存在服务器的 `memory.sqlite3`，与账号、设备和聊天记忆一起备份。默认向量服务为阿里云百炼 `text-embedding-v3`：文档文字会发送给供应商建立索引；提问时，问题会用于检索，相关片段会交给回答模型。这些调用使用服务端 API Key 并产生供应商计费，请仅上传有权使用且适合交给该服务处理的资料。

上传资料与个人聊天记忆分别管理。程序不直接把检索片段作为长期记忆写入，但聊天回答可能包含资料内容，并随聊天记录保存。删除文档后，当前资料库的原文件与索引会移除，后续检索不再引用；已有聊天、正在生成的回答和历史备份不会因此自动清除。历史备份中的资料随备份轮换或由管理员另行处理。

## 已验证与当前范围

已使用临时账号测试上传、检索、下载、重建、删除、跨账号拒绝、重启恢复及备份恢复，并检查电脑和手机页面。真实百炼调用验证了向量索引、普通文字资料问答，以及 `qwen3.8-omni-flash-realtime` 配合 `Tina` 的语音检索回答；语音测试使用合成音频输入。

普通 `qwen3.8-omni-flash` 不支持当前请求的音频输出参数时，文字通道自动改为文本回答并提示本次不播放声音。设备麦克风使用独立的实时语音接口。

本轮未重新打包 exe，未进行实体小猫的资料问答验收，也未进行 10～20 人并发压测。当前使用单个 Uvicorn worker 和 SQLite，适合先做小规模验证；实际容量需按服务器资源、资料数量和模型配额测试。

管理员可参考[服务器说明](../server/README.md)查看 API、环境变量、数据库备份和恢复步骤。

# 资料如何进入对话

上传后，后台会解析文档、生成检索索引，并用当前账号的 Key 生成一份简介、关键词和同义说法。模型暂不可用时保留原文，使用本地简介和关键词检索；可配置 Key 后重建索引。

聊天时先在本地判断话题，不为路由额外调用分类模型。命中关键词、同义说法或具体简介内容后，只在候选文档中查找；普通闲聊跳过检索。可以明确说「查一下我的资料」发起全库检索。资料页的手动检索始终搜索当前账号的资料。

相关问题后的短追问可沿用前一资料话题，最多三次、间隔不超过两分钟；换话题后清除。删除文件、账号切换、设备运行时销毁后不会沿用旧资料。检索路由采用保守规则，不能保证所有口语表达都命中。

在资料库点击「编辑话题」，可修正简介、关键词和同义说法，例如「请假、OA、审批」「年假、休假、调休」。手动设置会保留，重建索引不会覆盖。

首次生成简介和索引会产生模型用量；相关提问可能产生查询向量和回答用量。此优化减少无关请求，不能承诺固定比例的提速或费用下降。文档片段作为参考数据注入本轮，不把资料中的指令当成系统指令。

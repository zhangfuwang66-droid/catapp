# 赛博小喵（Cyber Miao）使用说明

## 一、已实现的功能

| 功能 | 说明 |
|---|---|
| 语音对话 | Qwen 3.5 Omni 端到端语音，流式输入/输出 |
| 视觉问答 | 对话时自动抓单帧摄像头画面传给模型 |
| 同声传译 | 中英互译（进入翻译模式后重建会话换脑） |
| 实时画面 | 网页 viewer 看摄像头画面（对话期间约 6fps 不冻结） |
| 屏幕显示 | TFT 屏幕只显示本地表情动画（节省带宽） |
| 舵机动作 | 表情动作、15 个动作库、待机随机动作 |
| WiFi 配网 | 连不上 WiFi 自动开热点，网页配网（可配置 WiFi + 服务器 IP） |
| 配网语音 | 进入配网时播放本地预录音频提示 |

## 二、需要烧录的文件

### 1. 主程序（必须）
```
esp32_servo_control/esp32_servo_control/esp32_servo_control.ino
```
烧录时使用自定义分区表 `esp32_servo_control/partitions.csv`（8MB flash，spiffs 约 5MB）。

### 2. 配网语音提示（可选，只做一次）
若想进入配网时有语音播报，先用工具写入 `config_prompt.pcm`：
1. 编译烧录 `esp32_servo_control/config_flash_files/config_flash_files.ino`（用同一份 partitions.csv）
2. 串口监视器（115200）输入 `W`，看到「写入完成」
3. 重新烧录主程序

没写这个文件也不影响配网，会自动退化为蜂鸣提示音。

## 三、启动步骤

1. 烧录主程序到 ESP32
2. 电脑上启动服务器：
   ```
   cd esp32_servo_control/server
   python app.py
   ```
   （监听 8081 端口，需要 `.env` 里的 DASHSCOPE_API_KEY）
3. ESP32 开机后自动连 WiFi（默认连上次保存的；连不上 30 秒后进入配网热点 `CyberMiao-Setup`）
4. 配网时填电脑当前的局域网 IP（用 `ipconfig` 查），保存后自动连接

## 四、常见问题

- **连不上服务器**：先 `ipconfig` 确认电脑当前 IP，配网时填这个 IP（不要填旧的 10.192.11.10）；再检查 Windows 防火墙是否放行 8081 端口。
- **配网进不去**：手机连 `CyberMiao-Setup` 热点后，浏览器访问 `192.168.4.1`。
- **网页打不开**：浏览器访问 `http://<电脑IP>:8081`。

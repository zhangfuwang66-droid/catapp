# 管理后台隐私边界

管理员后台用于账号、设备和服务运维。涉及用户私有资料与聊天记忆时，只能展示容量、数量、处理状态和删除阻断状态，不提供正文查看、检索、导出或下载能力。

允许的运维元数据包括账号和设备标识、账号名、设备显示名称、归属与借用关系、启停与在线状态、时间、数量、字节容量、保留模式和固定操作审计结果。`key_configured` 仅表示是否配置，不能展示用户模型 Key、掩码尾号或密文。

所有管理读接口（含首页、账号/设备详情和 storage）均禁止返回原始消息、聊天摘要、记忆事实、未完成话题、压缩归档内容、文档原文件/片段/资料摘要/关键词/别名、用户文件名、模型 Key、密码或凭证散列。账号及设备详情中的 `memory`、`documents`、`history` 是统计字段，不是正文入口。

审计仅保存操作者身份、目标编号、固定动作、结果和时间，不接收请求正文、密码、文档名、私有内容或任意异常详情。参数错误不能回显输入值；存储/清理/备份故障只能返回固定说明和可重试状态，不能回显路径、SQL 或异常正文。

备份 API 只展示校验时间、字节数、校验及任务状态，不返回备份文件名、目录、回执、摘要、原始数据库或下载地址。服务器离线备份文件包含用于恢复的用户私有数据，仍需由服务器维护者保护；“管理网页不能查看”不等于“离线数据库不含私有数据”，也不替代服务器文件访问控制。

后台资源通过受保护的规范路径提供；独立登录页及其精确公开资源以登录契约为准，不能整体公开后台目录。静态挂载不应暴露数据库、备份、凭证文件或设备记录。管理员资格不替代用户业务接口的归属检查：他人记忆和资料仍只能由原账号访问。

独立回归 `server/tests/test_admin_privacy_boundary.py` 在临时数据库中写入不同消息、摘要、记忆、话题、可还原压缩归档、文档正文/片段/资料摘要/关键词/别名/文件名以及模拟模型 Key。它遍历全部 11 个管理 GET 路由类型，核对统计值与哨兵不泄漏，覆盖普通账号/硬件凭证/撤权、用户归属、读取故障、参数错误、失败审计、真实本地备份和静态路径；原用户可正常读取的正向控制用于确认数据确实存在。新增管理 GET 路由必须更新独立隐私验收清单。

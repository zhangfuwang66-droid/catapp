# 完整管理后台独立验收清单

只对主对话指定的固定集成 HEAD 给出全量结论。此清单列出验收要求，不将尚未实现或尚未执行的项目标为通过。使用临时数据库、模拟账号、假模型和离线设备登记；不操作实体设备、不读取真实 Key、不启动虚拟机、不连接生产服务。

## 权限、并发与非法请求

- 未登录、普通账号、停用账号、设备 Bearer 对所有管理页面、读接口、详情及写接口逐项拒绝。保留正常登录的 CSRF 返回契约，其余管理元数据不包含秘密。
- 写请求覆盖缺失/错误 Origin、缺失/错误 CSRF、错误目标确认、格式错误、额外字段、未知目标、重复目标、已变化的目标。拒绝后数据、凭证、成员关系及私有历史不变。
- 两个管理员的 HTTP 请求均通过入口后竞争写锁，互相停用只能成功一次，至少保留一名启用管理员；失败方不能继续写入，审计仅反映真实执行结果。
- 排队等待全局锁、账号锁、设备锁或备份锁时撤销登录/角色、停用账号、取消请求；取得锁后及实际事务内重新授权。尚未开始的请求不得落库，已开始的合法操作须完整收尾。
- 故障注入审计写失败、连接清理失败、设备同步失败，区分未提交失败与已生效但未完成。503 不暴露异常原文或路径；仅允许操作者核对后执行安全收尾。

## 账号生命周期

- 新建普通账号、重复名称、大小写规范化、用户名边界和密码边界；响应、列表、详情、审计与验证错误不返回密码或散列。
- 网页仅验收实际提供的创建、详情、改名、启停、会话撤销和受保护空账号删除；创建请求不能授予管理员，未知字段不能改变角色。
- 自身保护、最后启用管理员保护、多管理员竞争、已撤销会话排队写入以及改名后旧登录失效均验证实际结果。密码重置仅限现有服务端工具，不列为网页能力。
- 有设备归属、借用、文档、聊天、记忆、保留策略或其他关联的账号不得被误删；符合契约的空账号删除后保留审计。被拒绝的删除不丢数据。

## 设备生命周期与秘密保护

- 覆盖 cat-、deer-、未知前缀、显示名称与类型相反的登记；类型由确切编号前缀判定，不能由显示名推断。
- 登记仅创建未绑定记录，凭证仅签发响应出现一次。重复编号冲突，路径穿越、超长编号、空名称、控制字符、额外字段拒绝；非法输入不回显令牌。
- 列表组合搜索、状态过滤、分页稳定无重复/遗漏，覆盖空页、最大页长、负页、非整数、SQL 片段、引号、百分号、下划线、HTML 和 Unicode。统计总数与筛选范围一致。
- 详情、列表、概览和 dashboard 不调用 registry.get/resolve，不读取模型凭证。递归核对返回白名单；不出现硬件明文令牌、散列、配对码、借用码、私人正文、文件名、模型密文、数据库绝对路径。
- 重命名只改显示名，不改变归属、授权代次、凭证、语音偏好和历史。确认错误、未知目标及等待期间归属/代次变化均拒绝。
- 轮换仅允许未绑定设备，旧令牌和待用配对码失效，新令牌可用；已撤销未绑定记录可重新启用，已绑定目标冲突。丢失响应不得自动再次签发。
- 借用期间管理员语音操作只改当前客人的偏好；主人原偏好不变。归还后恢复主人身份，旧客人授权失效，双方历史可各自读取且互不可见。
- 借用期间解绑/撤销结束借用与活动成员关系，旧授权代次失效。解绑保留凭证；撤销使全部旧凭证失效，双方历史及记忆保留。
- 有历史或保留策略的已撤销设备不能永久删除，详情给出删除阻止原因；空误登记只有先撤销后才可删除。再次登记同编号不能复活旧凭证；删除审计仍在。

## 首页与备份

- dashboard 使用真实近 7 个 UTC 自然日，覆盖空白日期、零数据、跨日边界、过期会话、失败资料、未绑定/撤销登记、未完成审计。最近审计上限为 8，管理操作不冒充 AI 用量或费用。
- 真实运行时的账号/代次/撤销状态与音频/摄像头连接影响在线数；离线、已关闭、错身份和 UI 单独连接不能伪报在线。
- 磁盘读取失败显示 unknown、容量为 null；低空间给出提示，错误不泄露路径；首页读失败可安全重试，不静默展示伪造健康状态。
- 未配置备份目录时手动检查返回 409。已配置专用临时目录时首次创建并校验，间隔内再次检查 created=false 且说明已有近期副本，不伪造新备份。
- history 仅返回最近 20 份校验通过的元数据，包含真实 total/skipped_unverified；损坏副本和回执不进入有效列表，路径、文件名、回执内容及数据库正文不返回。
- includes_provider_key=false 明示独立密钥不在快照中。未授权、无 CSRF、错误确认、目录注入、恢复/下载尝试被拒绝。
- scheduler_running 反映调度任务，running 仅在实际备份锁持有时为 true。排队失去权限不能开始备份；备份、恢复检查仅限临时目录。

## 浏览器、隔离交付与最终证据

- 桌面和手机验证 dashboard、账号/设备 CRUD 表单、详情、分页筛选、确认文案、冲突反馈、空态、备份反馈和审计；无控制台异常及水平溢出。
- 凭证只在当前内存弹窗内出现，复制/下载有配发提示，不写 localStorage/sessionStorage；关闭、刷新或离开后不残留。登记、轮换、删除不自动重试。
- 超时/断网/503 核对原目标状态，避免重复变更；旧解绑收尾不能误操作已经重新绑定的设备。
- preview_admin.py 在新进程导入前隔离业务环境并禁用 .env，监听 127.0.0.1，输出模拟账号和真实启用功能，使用临时 DB/备份和假模型。Ctrl+C 后目录删除，外部哨兵文件不变。
- 最终记录固定集成 HEAD、QA 本地提交、完整 Python 数量/跳过原因、各浏览器脚本结果、预览地址与停止方式。Linux/Python 3.10 没有实跑则明确保留未验证，不把语法解析或零作业 CI 当运行证据。
- 不推送、不新建远程分支、不修改其他工作树；本地提交中文说明，不加 Co-Authored-By。生产发布、数据库恢复和硬件配发均不在本次执行范围。

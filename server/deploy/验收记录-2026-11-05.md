## 记忆与数据库

真实摘要链路在 `probes/` 下独立的新建 SQLite 数据库中执行，未向运行数据库写入合成聊天。已验证：

1. 空闲后自动调用摘要模型并保存摘要。
2. `finish_conversation` 在对话结束时触发摘要。
3. 重新打开数据库后，已保存的两条摘要仍可读取。
4. 摘要会加入后续对话的记忆提示。
5. 另一用户和设备组合读不到这些内容；待总结消息在成功处理后清空。

为缩短验收时间，空闲触发测试使用 `0.3` 秒阈值和 `0.1` 秒巡检周期。**正式服务仍使用连续空闲 `300` 秒、默认每 `15` 秒巡检的配置**；这不是一次实际等待五分钟的整机测试，摘要完成还取决于模型响应时间。

正常服务关闭时的摘要收尾、未完成摘要的启动恢复，由自动化测试验证；本轮未为此重启正在运行的服务。设备断电后的处理仍取决于服务检测到断线；突然断电不等同于正常关机完成摘要。

运行数据库只读检查结果：

- 完整性、外键和归属关联检查均为 `ok`。
- schema 版本：memory `1`、identity `2`。
- 账号、登记设备、设备凭证各 `1` 个。
- 聊天、摘要、长期记忆、登录会话、配对码均为 `0`；未迁移历史聊天。
- 已有 `1` 份通过校验的自动备份，未验证而跳过的备份为 `0`。
- 数据库所在文件系统约使用 `24%`，可用空间约 `29 GiB`。

现有备份在同一服务器，不能替代异机备份。恢复流程使用临时数据库测试通过，但本轮未将任何备份恢复到正在运行的数据库。

## 本机访问方式

保持 SSH 隧道连接，在浏览器访问 `http://127.0.0.1:18081/`，使用 `owner` 和本次设置的密码登录。

需要重新连接时，在本机 PowerShell 执行：

```powershell
ssh -N -L 127.0.0.1:18081:127.0.0.1:8081 root@123.57.23.227
```

隧道断开只影响本机访问，云端服务仍由 systemd 运行。实体小猫不能通过这个仅供本机使用的地址连接云端。
